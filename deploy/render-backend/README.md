# Render Backend

Deploys eight request-driven services to Render.

Services: gateway, currency, identity, maps, attendance, health,
business, admin.

## Deploy

    export RENDER_API_KEY=...
    bash scripts/deploy-render.sh

## Environment

The envVarGroup techgeo-common holds shared values. Each service adds
SERVICE_NAME and PORT.

Secrets marked sync: false must be set in the Render dashboard:
POSTGRES_URL, MONGO_URL, REDIS_LEDGER_URL, REDIS_CACHE_URL,
KAFKA_BROKERS, HF_TOKEN.

JWT_SECRET and DEVICE_FINGERPRINT_SALT are generated by Render.

## Health Checks

Each service exposes GET /health. Render polls it after deploy.

## Free Tier

Free tier sleeps after 15 minutes. For production, use starter.
